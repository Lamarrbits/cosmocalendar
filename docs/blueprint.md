# **App Name**: Cosmic Calendar

## Core Features:

- Monthly Calendar View: Display astrological events in a monthly calendar view, with icons.
- Chronological List View: Display astrological events in a chronological list view.
- Daily/Weekly View: Display a summary of astrological events for the current day or week.
- Event Filtering: Allow users to filter astrological events by type.
- Event Searching: Allow users to search for events by date, astrological sign, or planet.
- Theme Switching: Enable automatic dark/light mode switching based on system settings, with a manual override.
- Localization: Provide full localization and internationalization support. Default language is Spanish.

## Style Guidelines:

- Primary color: Deep sky blue (#3498db) to represent the vastness of space. It gives a calm and trustworthy feeling.
- Background color: Light grayish-blue (#f0f8ff), for a clean and unobtrusive feel. Slightly desaturated of the primary color.
- Accent color: Soft purple (#9b59b6), which will be used to highlight important dates or events.
- Font pairing: 'Poppins' (sans-serif) for headlines and 'PT Sans' (sans-serif) for body text.
- Use celestial-themed icons for astrological events.
- Subtle animations and transitions to create a smooth and engaging user experience.
